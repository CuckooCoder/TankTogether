## 命令

在总目录使用 PowerShell：

```powershell
./tools/unity.ps1 -Action Open
# 以下命令需先保存并关闭本工程的图形编辑器
./tools/unity.ps1 -Action Verify
./tools/unity.ps1 -Action Build
```

Verify 配置工程并创建缺失的 Main 场景，已存在时不会重建场景内容。Build 输出 `Unity/TankTogether/Builds/Windows/TankTogether.exe`，为普通非 Development 构建。日志在工程 Logs 中。

编辑器加载完成后会连接 MCP；也可点击 `Tank Together > Environment > Connect MCP`。MCP 操作前必须选择正确实例并核对工程路径；共享服务上可能还有旧测试工程。

Codex 原生 MCP 工具目录是否加载需单独确认；可用本机 Python FastMCP 客户端调用同一服务。配置存在不代表连通。
