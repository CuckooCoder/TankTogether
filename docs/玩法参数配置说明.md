# 玩法参数配置

入口：Unity 顶部菜单 **Tank Together → 玩法参数**。

将鼠标停在**参数名称**上，可查看中文悬浮说明：控制什么、调大/调小的影响，以及相关参数与注意事项。全部31个参数（含折叠项、尺寸与只读参考）均已补齐；读取、保存、放弃草稿按钮也有说明。两个X/Z向量的第二格虽然被Unity标为Y，实际表示地面Z，悬浮说明中已注明。

1. 打开要测试的场景，例如 WhiteboxCarryLab，停止 Play。
2. 面板会显示当前场景引用的配置；切换场景后点击“读取当前场景配置”。白模当前使用 WhiteboxJumpTrial.asset。
3. 修改数值，点击面板顶部、配置路径下方的“保存参数（下次运行生效）”。编辑面板中的草稿不会立即影响游戏或源资产。
4. 再次 Play 测试。无需修改 C#，也无需重新编译脚本。

## 常用项

| 参数 | 用途 |
|---|---|
| 自由行走 / 自由奔跑 | 未抓鱼缸时的水平速度，米/秒 |
| 四人搬运行走 / 奔跑 | 四人抓取时的目标水平速度；实际结果受载荷、碰撞影响 |
| 搬缸起跳力度 | 实际按跳跃角色得到的向上速度增量；增大后通常跳得更高、更远 |
| 自由跳高 | 未抓取时的跳高目标，米 |
| 搬运刹停力度 | 保持抓取并松开方向输入时的减速力度；越大停得越快 |
| 缸底抬升参考 | 最近试调的参考记录，**不驱动跳跃**，只读；修改力度后以重新测量为准 |

“尺寸与初始站位”和“高级物理与抓取”可以展开，配置碰撞尺寸、出生站位、质量、阻尼、支撑、抓取范围和关节限距。

## 当前跳跃试调

2026-10-13：白模起跳力度9.3，平地四人近同步走跳约2.59米、跑跳约3.88米，相对最初6档分别增加61.1%和60.6%。缸底中心抬升约1.15～1.17米。百分比来自实际测量，不是“力度数值乘1.6”；这个位移也不等于能跨过同样宽的沟。

## 保存和协作

- 运行时面板只读，统一停止后修改并保存，下一次Play完整重建刚体与碰撞体，避免部分参数生效、部分仍用旧值。
- “放弃草稿”恢复已保存配置；常规修改支持Unity撤销。编译/Play切换保留面板未保存草稿，仍须点击保存才应用。
- 配置资产会跟随版本控制共享。当前白模配置位于 `Unity/TankTogether/Assets/Resources/WhiteboxJumpTrial.asset`，与其 `.meta` 一起提交。
- 原 `CarryBaseline.asset` 是 M0/M1/Steam 共用基线，面板会提示影响范围。现阶段试白模时使用独立配置。
- 改参数不会更新已发出的exe或ZIP；要让队友体验新值需重新打包并统一参数/地图版本。参数指纹仍参与联机兼容检查。
- 坡道反滑、镜头遮挡、后段路线和检查点等问题仍需逐项处理，不能依靠随意增大数值代替验证。
