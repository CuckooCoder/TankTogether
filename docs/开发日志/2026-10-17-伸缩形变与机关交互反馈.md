# 2026年10月17日反馈修复

## 程序改动

1. 默认Q变矮、E长高。旧默认Q/E组合迁移；自定义伸缩按键保留。新增可改键的机关交互，默认F；若旧自定义绑定占用F，为交互选择未占用键，现场提示显示实际绑定。
2. 白色机关真实接入本地和Steam输入链路。松开抓取后靠近按交互键立即切换目标端点，不要求其他玩家到齐或鱼缸上台、不再等两秒。到端点停止；暂停/碎缸停止，检查点重置恢复对应高度及方向。开关跟随平台移动，没有添加关卡中不存在的远程召回按钮。
3. 房主按真实发送者席位检查距离、抓取和阶段，客机只能申请。输入沿经可靠消息发送，旧序列/旧配置和非成员请求拒绝；快照包含当前方向。两人同时按键合并短间隔操作，避免同一物理步连续反转。协议升级18，不能与LevelLift-20261016协议17混联。
4. 伸缩恢复修复：原表现层只撤销平移偏移，没有恢复附加摆动/IK前的完整局部姿态，动画常量通道未覆盖时会残留旋转。现在保存每帧Animator基础姿态，在下一帧动画评估前恢复，再依次应用伸缩、摆动和接触IK。保留骨段长度、头帽五官保护和原有物理，不靠减弱摇晃参数掩盖问题。
5. 原空手下落重力倍率上限3无法输入反馈要求的4，编辑器校验、GM目录、Inspector范围及运行时限幅统一支持1～4；实际基线仍不改变。
