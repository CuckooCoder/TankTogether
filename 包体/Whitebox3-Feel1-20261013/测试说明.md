# 搬鱼缸 · Feel1 手感测试包

Windows x64；Steam App ID 480；基线 v0.2.3-whitebox-feel1。完整解压后运行 TankTogether-Steam.exe，不要单独发送 exe。

## 本轮变化

- 鱼缸改为开口的五面透明玻璃外观；物理外框与破碎判定保留。
- 默认尺寸仍为长3.2 × 宽2.2 × 高0.95米，放大目标待确认。可用本地 GM 调整长宽高，外观、碰撞和初始支架一起更新，质量另调。
- 鼠标上下视角放开到向上70度、向下80度；相机遇墙立即收近，离墙平滑回到原距离。
- 自由移动起步、转向和刹停更利落，坡面有静止补偿。增加0.10秒离地补跳与0.12秒提前按跳缓存。自由跳高仍为0.65米。
- 搬缸保持既有抓取、限力、重量和失败逻辑，不自动扶正。空手移动与搬运参数分开。
- Steam 状态目标发送频率20→30Hz，相机跟随拖尾缩短；加入方仍等待房主权威结果，尚未实现角色本地预测，不承诺消除网络延迟。

## 本地 GM

大厅选“本地模拟测试”，按 F1 打开/关闭 GM；打开时本地模拟暂停。

1. 在“人物走跳”调整速度、起步、刹停、空中修正、跳高和容错。
2. 在“鱼缸与搬运”调整鱼缸长宽高、质量、搬运速度/推力/刹停/起跳。每项有影响说明。
3. 点击“应用并重开本段”，当前检查点重新开始；关闭面板，按 Enter 操作。
4. “保存本机草稿”与“读取本机草稿”用于反复试调；读取后仍要点应用。重启不会自动加载。
5. “恢复随包参数”恢复本包默认值。返回大厅也会恢复，避免本地试调混入联机。

GM 文件在游戏 persistentDataPath（通常 %USERPROFILE%/AppData/LocalLow/DefaultCompany/Tank Together）下的 gm-local-whitebox-route-v3.json。不会修改 Unity 项目资产或联机存档。联机过程中不能用 F1 修改物理参数；确认一组参数后应写回 Unity 玩法参数并统一打包给双方。

## 联机测试

两端都使用本包，各登录不同 Steam 账号并互加好友。大厅选择“Steam 好友联机”，支持2～4人、至少2人开始。旧包与本包的参数签名不同，不能混用。

按 F3 显示网络状态：加入方显示应用层往返时间、距上次状态时间、最大状态间隔。请反馈：房主/加入方、自己的按键反应慢还是队友/鱼缸抖动，以及F3截图。该数值不是手指到屏幕的端到端延迟。

原有房主检查点存档可继续；本地练习不写入存档。尚无 Steam Cloud 与主机迁移。

WASD移动、鼠标看向、左键按住抓取/松开脱手、Shift跑、Space跳、Ctrl蹲、R从当前检查点重试。Enter开始操作、Esc释放鼠标。本地1单人/2同向模拟，Tab换角色。
