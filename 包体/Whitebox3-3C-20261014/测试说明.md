# 人物3C对照测试包 · 2026-10-14

Windows x64；Steam App ID 480；新版白模场景 SteamWhiteboxRevision3。
解压整个ZIP，运行 SteamWhitebox/TankTogether-Steam.exe。不要只取exe。

## 一个人比较手感
1. 启动选择“本地模拟测试”，按1切为单人自由测试，Enter开始操作。
2. 先用默认B新版走、停、反向、空手跳；比较按住方向与起跳后松方向。
3. F1 → 人物走跳 → A旧版对照 / B新版候选 → 应用并重开本段。
4. 关闭F1后重新开始。这会重开当前段，避免在运动中切换混杂状态。
5. F1顶部“一键复制当前生效参数”可以把全部53项发回；草稿未应用不会被复制。
6. 新版空中松键减速默认为8；方向控制仍为25。镜头上下跟随在“相机”分页，默认18。

新方案修正升降台接地/起跳，并保留适量空中水平惯性。地面起步、刹停、空手跳高、搬缸推力、碎裂和存档规则不变。
A旧版包含旧平台接地问题，仅供对照。这个A/B不是新策划的人物纵向伸缩实验，Q/E伸缩尚未实现。
