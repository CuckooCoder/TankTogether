# 碎缸失败流程原型 · 2026-10-13

完整解压后运行 TankTogether-Steam.exe，大厅可选本地模拟或Steam联机。
Unity入口仍为SteamWhiteboxCarryLab，玩法参数和地图未改变。

## 本地试玩
选择本地模拟，Enter开始，按住左键抓取/WASD搬运。让鱼缸接触危险地面/墙体会碎裂：
- 简易碎片和临时合成碎裂声，角色/鱼缸停止受力，显示“鱼缸碎了”。
- 约0.65秒后，可点击“从检查点重试”或按R；重试恢复完整鱼缸和角色，Enter重新开始操作。
- 可直接返回大厅；单人坠落只重生本人，不自动判全队失败。
- 目前仅登记实验起点，尚未接入正式中途停车检查点。失败不会覆盖既有存档。

## 联机
协议已升级tank-together-steam-04，不兼容之前03包。双方必须使用这份新包，选择Steam联机后接受邀请或粘贴房间号。
2～4人、至少2人开局。房主判定碎缸并发起检查点重试；队友等待，房间保留无需重邀。
失败时掉线/加入仍需等待成员连接恢复；不足两人禁止重试。房主返回大厅会结束房间。
存档是房主本地进度，未接Steam Cloud、主机迁移。App ID 480仅内部测试。

## 验证范围
本地真实危险碰撞/失败重试、存档不变和注入网络状态25项；M0操作24项；大厅21项与协议检查通过。
注入队友状态不是远程真人联机；真人异地效果仍待双方测试。
