# 白模3与阶段检查点测试包

- 解压整个 TankTogether-Whitebox3-20261013 文件夹，启动 TankTogether-Steam.exe，不要只拷贝 exe。
- 启动进入大厅，单人选“本地模拟测试”，异地选“Steam 好友联机”。两端都必须使用本包，协议05；Steam App ID 480，至少两个不同账号。
- 新地图：FishTank关卡白盒(3)。人物从低处黄球出发，鱼缸在中段原白色标记处；不是开局就在头顶。上层黄球是第二停车检查点。
- 检查点需鱼缸在四根棉花支撑上实际停稳；仅人物经过或缸悬空不保存。本地检查点仅本次模拟有效，Steam共同进度保存在房主本机。
- 碎缸后本地R重试；联机由房主重试。上层检查点激活后，人物回上层黄球，鱼缸回第二白标对应的安全支架，升降台恢复顶端。
- 升降台：当前实际所有玩家登台后连续等2秒，以2.5米/秒上升101米。等待期间离开会重新计时；开动后不会因有人走出而自动回程。
- 升降井有两个固定障碍，出口顶板覆盖部分区域，需避让。局部测试中，升降台中心向世界+X、+Z各偏2米的摆位，2人/4人携缸可完成全行程；这不是自动扶正或自动搬运。
- 新版存档为 prototype-whitebox-route-v3，旧地图存档保留，当前尚未接Steam Cloud或主机迁移。
- 编辑器入口：Tank Together → Steam → Open Whitebox Co-op；场景 SteamWhiteboxRevision3。旧场景保留回退。
- 已验：检查点16项、升降台22项、2/4携缸升降、失败回归25项、协议24项、本机检查点快照与准备恢复2项、Windows构建和单账号Steam烟测。
- 待验：两台电脑异地、真人升降避障手感、从起点连续全路线。测试中的局部摆位不等于已跑通整关。
