# V0.2.2 尺寸与运动基线测试包

2026-10-12。内部试调版本 `v0.2.2-r1`，非最终玩法定值。下载见 [私有预发布](https://github.com/1205971577/tank-together/releases/tag/baseline-20261012)。旧 Release 不包含这些改动。

## 选择测试包

- `TankTogether-M0-Baseline-20261012.zip`：本地物理实验，解压后运行 `TankTogether-M0.exe`。没有联网；默认其余三人复用输入，只用于验证四人施力。
- `TankTogether-Steam-Baseline-20261012.zip`：Steam 异地实验，解压后运行 `TankTogether-Steam.exe`。各自登录不同 Steam 账号、互加好友，房主创建房间并发数字房间号，其他人加入。App ID 480，最多四人。只验证过本机 Steam 建房、离开与重建，远端实测仍待团队完成。

必须完整解压，不能只发 exe。新旧测试包的参数及协议不同，不能混用；所有队友应下载同一 ZIP。

## 本轮验证内容

Enter 开始，WASD 移动，鼠标转镜头，左键按住抓取/松开脱手，Shift 奔跑，Space 仅控制自己的起跳，Ctrl 蹲下，R 重置（联网仅房主），Esc 释放鼠标。

本地实验另有 1 单人、2 四人同向、3 三顺一逆、4 两侧反向、Tab 换当前角色。默认同向模式的跳跃也是测试输入复制；实际联机没有团队起跳按钮。

重点试玩：四人起步/保持抓取停止移动、奔跑后刹停、松手换位、反向拉扯、单人和错时跳跃、蹲下、危险碰撞与重置。测试目标来自 V0.2.2；不能拿此包宣称已通过沟宽/台阶或三关。

本轮实测：自由移动4/6米每秒，四人搬运2.5/3.5米每秒；保持抓取刹停约1.12/1.93米；单人脚底跳高约0.65米，四人同步缸底中心抬升约0.53米。均为固定输入的物理测量，不代表真人手感验收。
