# 搬鱼缸 · 续玩与重连测试包（2026-10-15）

Windows x64 / Unity 6000.6.5f1 / Steam App ID 480 / 协议 tank-together-steam-12 / 存档 schema2。

这是内部测试候选包。所有队友必须换成这份包，不能与之前协议10/11的包混用。本包包含此前局外流程、平头支撑、64项统一调参与本轮恢复修复。尚未上传。

## 启动与联机

1. 完整解压 ZIP，运行 Windows-Test/TankTogether-Steam.exe。exe、Data 和 DLL 必须一起保留。
2. 一个人测试：主菜单右侧「进入关卡 · 伸缩 B」，不需要队友，不写合作存档。「更多测试工具」保留其他实验入口。
3. 联机：每人登录自己的桌面 Steam；所有成员使用一致的伸缩模式。房主「创建游戏」→选存档→创建房间，队友「加入游戏」粘贴房间号，或通过 Steam 邀请加入。
4. 开局需要2～4人，所有非房主主动准备，房主开始。角色按实际成员生成。
5. 房主退出会结束房间。没有主机迁移；需要同一房主重新建房、选择原存档再邀请。

## 本轮变化

- 跨次续玩保留同一冒险编号、检查点、累计时间和历史成员统计；队友不继承或覆盖房主存档。
- 损坏存档选择失败时保持原槽及当前内存进度，不用新档覆盖坏文件。
- 保存失败提供取消、重试保存并退出、两次确认放弃未保存部分。最后一种会丢失最近一次成功保存之后的时间与统计；已有磁盘档保留。按Esc取消后，下次放弃必须重新确认。
- 意外断线返回主菜单，显示原因和「重试上次房间」。仅在本次程序运行内记住房间；整个程序关闭后使用原房间号或邀请重新加入。重试仍由原房主和稳定Steam身份审核，不能保证已关闭的房间可恢复。
- 原成员重连从已激活检查点单独出生，不回滚鱼缸或其他成员；抓取键必须真实松开再按，避免重连误抓。
- 主动离队者不能重新加入本局；普通掉线不暂停其余玩家，即使暂时只剩一人也继续。本规则按后续V1.1实施，替代早期暂停重开原型。
- Steam请求/连接/同步超时有返回与重试提示，避免一直卡在等待中。

## 操作与调参

WASD移动，Shift跑，Space跳，按住鼠标左键抓取；B模式Q长高/E变矮。以个人设置中的当前绑定为准。Enter进入操作，Esc个人/房间菜单。个人菜单不暂停其他人，打开会释放本人主动抓取。

F1 GM含64项统一参数，F2直达伸缩；房主应用并同步，配置变化要求重新准备/从检查点继续。支持一键复制当前配置。编辑器「Tank Together/玩法参数」导入GM配置到草稿，显式保存后下次Play生效；已打出的包不会自动更新。

F3网络诊断。F4单角色、Shift+F4全体传送到鱼缸附近仅本地测试可用，联机禁用。GM可以关闭头顶支撑面的调试显示。普通个人设置与GM暂停行为不同。

显示设置15秒不确认自动还原；异常画面可加启动参数 -safe-display 恢复窗口。GM和部分开发标签仍为中文。

## 存档与测试注意

房主五槽，旧档仍为槽1；存档schema2兼容此前Formal包。旧格式首次升级保留.legacy-v1，勿用旧程序交替改同一槽。默认路径：%USERPROFILE%/AppData/LocalLow/DefaultCompany/Tank Together/CoopCampaigns/，按Steam身份隔离。

只从合法检查点恢复，不保存正在空中的鱼缸物理姿态。统计约每10秒及关键事件保存，崩溃仍可能丢最后一段未保存统计。自动验证用了独立测试目录，没有改用户正式存档。Steam Cloud仍需游戏自己的App ID和跨设备验证，480测试不证明云存档已启用。

## 建议两人异地按顺序验收

1. 新建或选择专用测试槽，加入、准备、开始；确认只有两名角色、伸缩和抓取正常。
2. 真正搬到一个检查点，正常退出并关闭程序。房主重新启动选原槽，核对检查点、时间、历史成员；队友自己的存档不变。
3. 搬运中客机意外断网，待房主确认离线；原账号网络恢复后重试房间。检查仅此人在CP出生，鱼缸与队友不回滚。
4. 客机整个程序意外退出后，以原房间号/邀请重入。重连时按住鼠标左键，应该先松开再按才能抓缸。
5. 另测主动离队，再尝试进同一局应被拒绝；重开一局后可以正常加入。
6. 房主退出或故障：客机应回主菜单、有原因，不能无限等待；房主重建后共同从最近成功保存的检查点继续。
7. 碎缸重试、最后一组四柱通关、投票结算、各自返回、再次挑战；检查报告和旧历史保留。
8. 调参和切显示设置，核对应用/复制/15秒回退。最后再从起点连续跑完整路线，勿把F4或测试夹具当全程验收。

反馈请带包名、房主/客机、人数、检查点、操作顺序及F3截图。异常日志在上述LocalLow的Tank Together目录下Player.log；下次启动前先复制保留。
