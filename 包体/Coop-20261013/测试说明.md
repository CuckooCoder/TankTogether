# 好友合作与房主存档测试包

版本：Coop-20261013，协议 tank-together-steam-03，Windows x64，Steam App ID 480 内部验证。新旧包不兼容，请所有人使用本目录同一ZIP。此包使用现有白模路线；本地白模原场景保留。

## 开始

1. 两台不同电脑分别登录自己的桌面 Steam 账号，互加好友，双方先完整解压并运行 `TankTogether-Steam.exe`。
2. 房主点“创建房间 / 继续房主进度”，然后“邀请 Steam 好友”；若覆盖层不显示，用“复制房间号”发给队友，队友在游戏里粘贴加入。
3. 实际加入几人就出现几个人物，支持 2～4 人。只有一人时不能开始。各端完成同步后，房主点“从最近检查点开始 / 继续”。
4. Enter 操作、WASD 移动、鼠标转向、左键抓取、Space 跳跃、Ctrl 蹲下、Shift 奔跑。Esc 打开房间菜单。两人模式默认前后站位，并有双方抓取时的有限抗翻转辅助。
5. 队友加入、退出或连接失联后全队暂停。至少两人连接恢复后，房主从检查点重开本段。R 先暂停准备重开，随后由房主点继续。原房主退出后本次会话结束，需同一房主重新建房。

## 存档边界

房主本地保存，按 Steam 账号隔离，队友不会覆盖自己的进度。目录是 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/Tank Together/CoopCampaigns/<房主SteamID>/`。有校验、原子写入、备份与版本检查。

**本包只登记白模起点 `whitebox-route/start`。继续游戏目前回到起点；白模中途停车点尚未接成正式自动存档。** 不保存空中坐标/速度，不含 Steam Cloud，不含主机迁移。正式检查点位置与激活条件要依据策划确认后接入。

## 必测结果（目前待双真人验证）

- 双人分别观察角色总数、移动、抓取、跳跃；第三/第四人加入应先暂停，不能偷偷多出空角色。
- 在双方游戏已运行时接受好友邀请；用数字房间号做备用路径。
- 其中一人退出→剩一人不得继续；重新加入→房主开始→两端从同一起点恢复，旧按键不能自动抓取。
- 房主离开→队友回到房间入口；同一房主重新建房→正常读取自己的存档。
- 网络中断时停止模拟/显示断线提示，恢复后重新从检查点开始。

本地协议、存档、人数物理、单账号建房检查不能替代这些测试。两人整张白模通关和异地手感尚未验收；前一轮四人连续跑测发现环形长沟阻塞，尚未在本轮调整关卡。

480 不是本游戏正式 Steam App ID。未启动游戏时的邀请拉起路径与 Steam Cloud 要等自有 App ID 配置后验证。
