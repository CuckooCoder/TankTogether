# 搬鱼缸 · 联机 GM 调参测试包

Windows x64，Steam App ID 480，协议 tank-together-steam-06。完整解压运行 TankTogether-Steam.exe。所有队友必须使用这份 GM 包，不能与 Feel2 / Feel1 / R2 混联。旧包保留。

## 怎么调、怎么复制

1. 进入本地模拟，或创建/加入 Steam 房间，按 F1 打开 GM。
2. 参数分为人物走跳、尺寸站位、鱼缸搬运、抓取支撑、两人辅助、相机、机关联机，共50项。每项有中文作用说明和范围；可按中文名/代码字段搜索，参数较多时滚动面板。
3. 顶部“一键复制当前生效参数”直接复制完整 JSON；可发给策划/程序，或粘贴到文本文件。复制的是已应用数值，不包括未应用草稿。
4. “从剪贴板导入草稿”读回整套参数，校验通过后仍需点击应用。本机草稿也可保存/读取；文件路径为 Unity persistentDataPath 下 gm-local-关卡ID.json。旧版只含人物/鱼缸的本机草稿可读取，新增参数保留当前值。
5. 联机只有房主可编辑/应用。应用会暂停全员并从房主当前检查点重建；队友自动接收配置，版本和哈希确认齐后，关闭 GM，由房主开始本段。晚加入自动拿房主当前配置。
6. 队友可打开 GM 查看/复制，不能改房间参数；查看时也会请求暂停保护鱼缸。所有人关闭 GM 后才能继续。
7. “随包参数→草稿”仅填入草稿；点击应用才恢复。退房/返回大厅恢复随包配置，重新建房需重新读入并应用草稿。GM不永久修改工程参数资产，不把试调值写入共同进度存档。

## 联机验收建议

- 两个不同 Steam 账号互加好友，两人都运行本包；房主建房，队友加入。
- 房主 F1 改“行走速度”为5.0，应用；看配置版本/短哈希相同、确认人数2/2。关闭GM，由房主开始；两端速度一致。
- 队友 F1只能查看/复制，房主在其关闭之前不能继续；复制内容应与房主当前值一致。
- 房主再改鱼缸尺寸、搬运推力或相机参数；每次应用后从当前检查点开始，检查外观、碰撞和抓取一致。
- 改参后让第三人或重连队友加入，确认自动获得最新参数；退房重建应恢复随包值。
- F3查看加入方应用层往返、快照间隔。提高状态频率会增加带宽，不能凭此消除网络延迟；尚无本地预测。

## 保留与边界

- 默认空手下落倍率2、跳高0.65m；保留用户最新空中修正25。鱼缸默认仍长3.2×宽2.2×高0.95m，可GM试调放大。
- 2～4人、房主存共同进度、两人轻度抗翻转、碎缸失败和检查点恢复规则不变。地图保持白模3 R2，旧检查点存档可继续。
- 不开放世界重力、物理步长、地图坐标、升降总行程、存档格式等结构性设置。旧 motorGain/motorForce 已停用，不显示为有效调参；carryJumpHeightTarget 仅记录参考。环境说明包含在复制内容中。
- 本地GM/客户端配置处理和权限专项36项、协议24项、手感相机回归15项通过。实际Windows单账号Steam建房/重建、GM应用/剪贴板/恢复默认通过；没有证明真实双账号异地同步或整关连续通关，后两项仍待测试。
